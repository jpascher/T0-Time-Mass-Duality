\section*{What this is about}

The recurring objection to FFGFT is: ``$\xi$ is fitted to the lepton
masses, hence circular.'' This note shows that the objection rests on a
misunderstanding of the hierarchy.

The correct order is: \textbf{overarching} is the geometry that
possesses resonances — dimensionless, fixing all ratios. The
\textbf{anchor} is a single measured value — carrying no structure, only
the scale. The measured value is the tuning pitch, not the music.

Not part of the A-series.

           {(\sqrt{m_e}+\sqrt{m_\mu}+\sqrt{m_\tau})^2} = \frac{2}{3}.

No measured value needed — only the ratios of the masses.

\textbf{(2) Generation ladder [K].} The charged leptons realize the

$Q = 2/3$ — the same number orders the ladder and the mass relation

$r_\mu = 16/5$, $r_\tau = 25/9 = (5/3)^2$ — intervals in the Euler

\chapter{Why This Resolves the Circularity}

The objection: ``$\xi$ is fitted to the masses.'' The answer: yes — the
absolute \emph{scale} (the tuning pitch) is measured. But the
\emph{structure} (the resonances) is not fitted. It is \textbf{confirmed}
by $Q = 2/3$, not set.

The proof is in the residual
(\texttt{ffgft\_310\_koide\_referenz.py}):
\[
  Q_\text{measured} - \tfrac{2}{3} = -6.2 \times 10^{-6} \neq 0.
\]
A fit would have hit $Q$ exactly ($0.000\%$). The geometry hits $Q$ to
$10^{-5}$ \emph{with a residual} — the signature of a genuine prediction.

\chapter{The Choice of Starting Point Is Convention}

There is \textbf{one} dimensionless number world. $\xi$, $\alpha$, $Q$,
$m_\mu/m_e$ are different coordinates in it — none more ``fundamental.''
The circularity is not $\xi$-specific: ``why $\alpha = 1/137$?'', ``why
$Q = 2/3$?'', ``why $\xi = 1/7500$?'' are all open. Every theory must set
some dimensionless number somewhere.

The only real difference is \textbf{one networked posit vs.\ many
isolated ones}: the SM has 3 independent lepton masses; FFGFT saves one
number via $Q = 2/3$ and connects, via $\xi$, the lepton sector to
cosmology ($a_0$, $H_0$). The gain is real but modest — not ``everything
from nothing,'' but a reduction with direction.

\chapter{Why Mixing QM and RT Is Legitimate}

The usual objection — ``you mix $\hbar$ (quantum) with $c$ (relativity)''
— is not defended but inverted: the \textbf{separation} QM$|$RT is the
artificial thing, not the mixing.

\textbf{(1)} $\hbar$ and $c$ are both only unit bridges
(space$\leftrightarrow$time, energy$\leftrightarrow$time). Neither is a
theory. Using both at once is permitted.

\textbf{(2)} The T$^4$ structure needs both (P34): $c$ is the space-time
bridge, $\hbar$ the mass-time bridge. Setting $c=\hbar=1$ collapses the
geometry. To see it, one must mix.

\textbf{(3)} $\tilde T \cdot m = 1$ \emph{is} the mixing: proper time
(RT) times mass (QM). Physics has long mixed them anyway — Dirac, QFT,
Unruh, Hawking. FFGFT only makes it explicit.

\textbf{(4)} The conflict is one of interpretation, not formalism. Per
Doc.~230, instantaneity is a description artefact; on T$^4$ Bell
correlations are topologically connected, not ontologically non-local.
Correct the interpretation and mixing becomes necessary.

\textbf{Core statement.} To forbid the mixing is to forbid the geometry.
