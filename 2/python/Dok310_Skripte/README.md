# Dok. 310 — Prüfskripte

Vier Skripte zur Resonanzgeometrie-Referenz. Keine freien Parameter,
alle Eingaben deklariert (PDG-Massen, CODATA-Konstanten).

| Skript | Prüft |
|---|---|
| `ffgft_310_koide_referenz.py` | Q = 2/3 aus 3 Massen, parameterfrei; Winkel 44,9997° |
| `ffgft_310_massenleiter.py` | glatte Bausteine → krumme Verhältnisse (m_μ/m_e etc.) |
| `ffgft_310_pi_geometrie.py` | 16π³ = S²·2S³; μ₀-4π kürzt sich in α |
| `ffgft_310_higgs_zugang.py` | xi aus Higgs-Sektor (2% Treffer, Querverankerung) |

Ausführung: `python3 <skript>.py` — jedes ist eigenständig.
