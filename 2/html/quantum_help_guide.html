🎯 Grundlagen & Erste Schritte

Was ist dieser Quantum Simulator?

Der Simulator führt Shors Periodenfindung als klassische Ordnungssuche im Browser aus und bietet einfache Qubit-Gatter als Lehrmodell. Ein eigenes FFGFT-Faktorisierungsverfahren gibt es nicht (Dok. 190, R65); die Rechnungen der Standard-QM bleiben verwendbar, FFGFT deutet sie als Resonanzvorgänge.

🎮 Schnellstart: Geben Sie eine Zahl (z.B. 77) ein und klicken Sie auf "🚀 Ordnungssuche starten". Der Simulator sucht die Ordnung von a = 2 modulo N und gewinnt daraus die Faktoren.

Wichtige Begriffe:

  • Ordnungssuche: Gesucht ist das kleinste r mit ar ≡ 1 (mod N); bei geradem r liefert ggT(ar/2 ± 1, N) die Faktoren (Shor-Extraktion)
  • Feste Basis: Alle Modi verwenden a = 2
  • Primzahlprüfung: Findet "🚀 Ordnungssuche starten" keine Faktoren, prüft eine Probedivision, ob N eine Primzahl ist
  • Deterministische Lesart der Messung: Die (unbekannte) Apparatgröße λ legt jeden Einzelausgang fest; der Simulator wählt λ bei jeder Messung neu
  • Qubit: Die Grundeinheit der Quanteninformation
  • Superposition: Ein Qubit kann gleichzeitig in mehreren Zuständen existieren
  • Verschränkung: Qubits können so verbunden werden, dass sie sich gegenseitig beeinflussen (im Einzelqubit-Lehrmodell nicht dargestellt)

🚀 Erste Schritte:

  1. Geben Sie eine Zahl zum Faktorisieren ein (empfohlen: 15, 21, 35, 77, 143; N ≤ 1023)
  2. Wählen Sie eine der vier Schaltflächen
  3. Verfolgen Sie die Ausgaben im Ergebnisfeld
  4. Experimentieren Sie mit Primzahlen (7, 11, 13, 17, 19, 23) und "🚀 Ordnungssuche starten"
  5. Verwenden Sie Quantum Gates für direkte Qubit-Manipulation

🚀 Die vier Faktorisierungs-Schaltflächen

Vier verfügbare Modi:

🚀 Ordnungssuche starten

Hauptmodus

Ordnungssuche mit Basis a = 2 in Schritten mit Fortschrittsanzeige. Findet sie keine Faktoren, prüft eine Probedivision, ob N eine Primzahl ist.

Geeignet für: kleine zusammengesetzte Zahlen (N ≤ 1023)

⚛️ Ordnungssuche (schnell)

Ohne Fortschrittsanzeige

Dieselbe Ordnungssuche mit Basis a = 2; gibt Faktoren, Laufzeit und Bitlänge von N aus. Keine Primzahlprüfung.

Geeignet für: Schnelle Tests

🧠 Bell + Grover + Ordnungssuche

Zwei Modellrechnungen vorab

Berechnet zuerst den Bell-Zustand |Φ+⟩ und eine Grover-Iteration mit 3 Qubits (Ziel |101⟩, P = 25/32 ≈ 0,78), danach dieselbe Ordnungssuche. Die Faktorisierung ist mit den anderen Modi identisch.

Geeignet für: Kennenlernen von Bell- und Grover-Schritten

📊 Vergleich mit Probedivision

Laufzeitvergleich

Führt die Ordnungssuche und eine Probedivision bis √N nacheinander aus und zeigt beide Ergebnisse mit Laufzeit. Beide Verfahren sind klassisch.

Geeignet für: Lernzwecke, Zahlen, bei denen a = 2 versagt

Was alle Modi gemeinsam haben:

  1. Feste Basis: a = 2 (das Feld "Basis a" ist nur Anzeige)
  2. Suchbereich: Perioden r < min(N, 2000)
  3. Shor-Extraktion: bei geradem r werden ggT(2r/2 − 1, N) und ggT(2r/2 + 1, N) geprüft
  4. Grenze: Ist die Ordnung ungerade oder 2r/2 ≡ −1 (mod N), findet die Suche keine Faktoren (z. B. N = 33, 57, 65)

🔍 Primzahlen

Warum Primzahl-Erkennung wichtig ist:

Primzahlen können mathematisch nicht faktorisiert werden, da sie nur durch 1 und sich selbst teilbar sind. Der Modus "🚀 Ordnungssuche starten" meldet sie deshalb als Primzahl statt als Fehlschlag; die anderen Modi melden nur "keine Faktoren gefunden".

🔬 Probedivision

Prüft die Teiler 2, 3, 4, … bis √N; für N ≤ 1023 exakt und schnell.

🔁 Reihenfolge

Zuerst läuft die Ordnungssuche; erst wenn sie keine Faktoren liefert, folgt die Probedivision.

Beispiel-Ausgaben:

Eingabe: N=23 (Primzahl) 🚀 Starte Ordnungssuche (Shor-Extraktion) für N=23 📊 Basis a = 2; ξ = 4/30000 hat keinen Einfluss auf die Faktorisierung 🔍 Probedivision: N=23 ist PRIMZAHL (keine Faktoren vorhanden) ✅ Bestätigt: 23 ist PRIMZAHL
Eingabe: N=77 (Zusammengesetzt) 🚀 Starte Ordnungssuche (Shor-Extraktion) für N=77 📊 Basis a = 2; ξ = 4/30000 hat keinen Einfluss auf die Faktorisierung 🔍 Periode gefunden (klassische Ordnungssuche) ⚛️ Ergebnis: 7 × 11 = 77 🎉 Faktorisierung bestätigt: 7 × 11 = 77

🎛️ Qubit-Steuerung

Qubit-Zustände verstehen:

🔴 Zustand |0⟩

Klassischer "Aus"-Zustand. Qubit ist definitiv in Position 0. Wahrscheinlichkeit: 100% für 0, 0% für 1.

🟢 Zustand |1⟩

Klassischer "An"-Zustand. Qubit ist definitiv in Position 1. Wahrscheinlichkeit: 0% für 0, 100% für 1.

⚡ Superposition

Quantenzustand: Qubit ist gleichzeitig 0 UND 1. Bei der Messung legt die Apparatgröße λ den Ausgang fest.

🧪 Experiment 1: Superposition erkunden

  1. Setzen Sie alle Qubits auf |0⟩ (Reset All)
  2. Klicken Sie "Superposition" - alle Qubits blinken jetzt
  3. Klicken Sie mehrmals "Measure All" und beobachten Sie die Ergebnisse
  4. In der deterministischen Lesart legt die (unbekannte) Apparatgröße λ jeden Einzelausgang fest; der Simulator wählt λ bei jeder Messung neu, daher erscheint |0⟩ mit der Häufigkeit (1+z)/2 (z = Bloch-Koordinate, Born-Regel)

🚪 Quantum Gates

Quantum Gates sind die "Bausteine" der Quantenberechnung. Sie transformieren Qubits mathematisch präzise.

Single-Qubit Gates:

H - Hadamard Gate

Funktion: Erzeugt Superposition
|0⟩ → (|0⟩ + |1⟩)/√2
|1⟩ → (|0⟩ - |1⟩)/√2

X - Pauli-X Gate

Funktion: Bit-Flip (Quantum NOT)
|0⟩ → |1⟩
|1⟩ → |0⟩

Y, Z, S, T

Funktion: Phasengatter
Z: |1⟩ → −|1⟩, S: |1⟩ → i|1⟩, T: |1⟩ → eiπ/4|1⟩
Die Phasen bleiben erhalten (T·T = S); sichtbar werden sie erst nach einem weiteren H.

CNOT Gate

Funktion: Controlled NOT
Flippt Target nur wenn Control = |1⟩
In der Quantenmechanik erzeugt CNOT Verschränkung; das Einzelqubit-Lehrmodell stellt sie nicht dar.

🧪 Experiment 2: Bell-Zustand erzeugen

  1. Reset All Qubits
  2. Wählen Sie Qubit 0 als Target, klicken Sie "H (Hadamard)"
  3. Setzen Sie Control = 0, Target = 1
  4. Klicken Sie "CNOT Gate"
  5. Ergebnis: Im Lehrmodell wird das Ziel-Qubit geflippt; ein echter verschränkter Zustand wird von diesem Einzelqubit-Modell nicht dargestellt.

🚀 Erweiterte Konzepte

Bezug zur FFGFT:

  • ξ-Parameter: fest ξ = 4/30000; in diesem Lehr-Simulator ohne Einfluss auf die Faktorisierung
  • Periodenbewertung: keine; die Periode stammt allein aus der Ordnungssuche
  • Basis: fest a = 2; es werden keine weiteren Basen versucht
  • Deterministische Lesart: Der Einzelausgang ist durch λ festgelegt; die Häufigkeiten folgen der Born-Regel

Bloch-Sphere verstehen:

  • Nord-Pol: |0⟩ Zustand
  • Süd-Pol: |1⟩ Zustand
  • Äquator: Superposition
Komplexität: Shor theoretisch O((log N)³); ein allgemeiner exponentieller Quantenvorteil ist nicht belegt, im erreichbaren Bereich faktorisiert ein klassischer Rechner ebenso schnell (Dok. 176, Dok. 384).

🔧 Problemlösung & FAQ

Häufige Fragen:

❓ Warum blinkt mein Qubit?

Antwort: Superposition! Das Qubit ist gleichzeitig 0 und 1. Das ist korrekt und gewünscht.

❓ Warum findet der Algorithmus keine Faktoren?

Mögliche Gründe:
• Die Zahl ist eine Primzahl (mathematisch korrekt)
• Die Ordnung von 2 ist ungerade oder 2r/2 ≡ −1 (mod N) → "📊 Vergleich mit Probedivision" verwenden
• N ist gerade: dann ist 2 kein geeigneter Basiswert, der Faktor 2 ist offensichtlich

❓ Welcher Modus ist der beste?

Antwort: Für die Faktorisierung sind alle gleich, sie verwenden dieselbe Ordnungssuche. "🚀 Ordnungssuche starten" meldet zusätzlich Primzahlen.

❓ Was bedeutet "ist PRIMZAHL"?

Antwort: Das ist ein korrektes Ergebnis. Primzahlen können mathematisch nicht faktorisiert werden; die Probedivision hat bestätigt, dass N keinen Teiler bis √N hat.

Fehlerbehebung:

Problem: "Ordnungssuche mit Basis a = 2 fand keine Faktoren"
Lösung: N ist zusammengesetzt, aber die Basis 2 ist für dieses N ungeeignet. Verwenden Sie "📊 Vergleich mit Probedivision".
Problem: "Keine Faktoren gefunden" bei einer Primzahl
Lösung: Die Modi "⚛️ Ordnungssuche (schnell)" und "🧠 Bell + Grover + Ordnungssuche" prüfen nicht auf Primzahlen. Verwenden Sie "🚀 Ordnungssuche starten".

2. Verwenden Sie "📊 Vergleich mit Probedivision" für Grenzfälle
3. Testen Sie bewusst Primzahlen vs. zusammengesetzte Zahlen
4. Experimentieren Sie mit Quantum Gates für das Verständnis
5. Verstehen Sie die mathematischen Grundlagen

🎯 Basics & Getting Started

What is this Quantum Simulator?

The simulator performs Shor’s period finding as classical order finding in the browser and offers simple qubit gates as a teaching model. There is no FFGFT-specific factorization procedure (Doc. 190, R65); the calculations of standard QM remain usable, and FFGFT interprets them as resonance processes.

🎮 Quick Start: Enter a number (e.g., 77) and click "🚀 Start order finding". The simulator searches for the order of a = 2 modulo N and obtains the factors from it.

Key Terms:

  • Order finding: The smallest r with ar ≡ 1 (mod N) is sought; for even r, gcd(ar/2 ± 1, N) yields the factors (Shor extraction)
  • Fixed base: All modes use a = 2
  • Primality check: If "🚀 Start order finding" finds no factors, trial division checks whether N is prime
  • Deterministic reading of measurement: The (unknown) apparatus variable λ fixes each individual outcome; the simulator chooses λ anew for every measurement
  • Qubit: Basic unit of quantum information
  • Superposition: A qubit can exist in multiple states simultaneously
  • Entanglement: Qubits can be connected to influence each other (not represented in the single-qubit teaching model)

🚀 First Steps:

  1. Enter a number to factorize (recommended: 15, 21, 35, 77, 143; N ≤ 1023)
  2. Choose one of the four buttons
  3. Follow the output in the results panel
  4. Experiment with prime numbers (7, 11, 13, 17, 19, 23) and "🚀 Start order finding"
  5. Use Quantum Gates for direct qubit manipulation

🚀 The Four Factorization Buttons

Four Available Modes:

🚀 Start order finding

Main mode

Order finding with base a = 2 in steps with a progress display. If it finds no factors, trial division checks whether N is prime.

Suitable for: small composite numbers (N ≤ 1023)

⚛️ Order finding (quick)

Without progress display

The same order finding with base a = 2; outputs the factors, run time and bit length of N. No primality check.

Suitable for: Quick tests

🧠 Bell + Grover + order finding

Two model calculations first

First computes the Bell state |Φ+⟩ and one Grover iteration with 3 qubits (target |101⟩, P = 25/32 ≈ 0.78), then the same order finding. The factorization is identical to the other modes.

Suitable for: Getting to know Bell and Grover steps

📊 Comparison with trial division

Run-time comparison

Runs the order finding and a trial division up to √N one after the other and shows both results with their run times. Both procedures are classical.

Suitable for: Learning purposes, numbers for which a = 2 fails

What all modes have in common:

  1. Fixed base: a = 2 (the field "Base a" is display only)
  2. Search range: periods r < min(N, 2000)
  3. Shor extraction: for even r, gcd(2r/2 − 1, N) and gcd(2r/2 + 1, N) are tested
  4. Limit: If the order is odd or 2r/2 ≡ −1 (mod N), the search finds no factors (e.g. N = 33, 57, 65)

🔍 Prime Numbers

Why Prime Detection is Important:

Prime numbers mathematically cannot be factorized as they are only divisible by 1 and themselves. The mode "🚀 Start order finding" therefore reports them as prime instead of as a failure; the other modes only report "no factors found".

🔬 Trial Division

Tests the divisors 2, 3, 4, … up to √N; exact and fast for N ≤ 1023.

🔁 Order of Steps

The order finding runs first; trial division follows only if it yields no factors.

Example Outputs:

Input: N=23 (Prime) 🚀 Starting order finding (Shor extraction) for N=23 📊 Base a = 2; ξ = 4/30000 has no effect on the factorization 🔍 Trial division: N=23 is PRIME (no factors exist) ✅ Verified: 23 is PRIME NUMBER
Input: N=77 (Composite) 🚀 Starting order finding (Shor extraction) for N=77 📊 Base a = 2; ξ = 4/30000 has no effect on the factorization 🔍 Period found (classical order finding) ⚛️ Result: 7 × 11 = 77 🎉 Factorization verified: 7 × 11 = 77

🎛️ Qubit Control

Understanding Qubit States:

🔴 State |0⟩

Classical "off" state. The qubit is definitely in position 0. Probability: 100% for 0, 0% for 1.

🟢 State |1⟩

Classical "on" state. The qubit is definitely in position 1. Probability: 0% for 0, 100% for 1.

⚡ Superposition

Quantum state: the qubit is 0 AND 1 at the same time. On measurement, the apparatus variable λ fixes the outcome.

🧪 Experiment 1: Exploring Superposition

  1. Set all qubits to |0⟩ (Reset All)
  2. Click "Superposition" - all qubits are now blinking
  3. Click "Measure All" several times and observe the results
  4. In the deterministic reading, the (unknown) apparatus variable λ fixes each individual outcome; the simulator chooses λ anew for every measurement, so |0⟩ appears with frequency (1+z)/2 (z = Bloch coordinate, Born rule)

🚪 Quantum Gates

Quantum gates are the "building blocks" of quantum computation. They transform qubits with mathematical precision.

Single-Qubit Gates:

H - Hadamard Gate

Function: Creates superposition
|0⟩ → (|0⟩ + |1⟩)/√2
|1⟩ → (|0⟩ - |1⟩)/√2

X - Pauli-X Gate

Function: Bit flip (quantum NOT)
|0⟩ → |1⟩
|1⟩ → |0⟩

Y, Z, S, T

Function: Phase gates
Z: |1⟩ → −|1⟩, S: |1⟩ → i|1⟩, T: |1⟩ → eiπ/4|1⟩
The phases are preserved (T·T = S); they only become visible after a further H.

CNOT Gate

Function: Controlled NOT
Flips the target only if control = |1⟩
In quantum mechanics, CNOT creates entanglement; the single-qubit teaching model does not represent it.

🧪 Experiment 2: Creating a Bell State

  1. Reset all qubits
  2. Select qubit 0 as target, click "H (Hadamard)"
  3. Set control = 0, target = 1
  4. Click "CNOT Gate"
  5. Result: In the teaching model the target qubit is flipped; a genuine entangled state is not represented by this single-qubit model.

🚀 Advanced Concepts

Relation to FFGFT:

  • ξ parameter: fixed ξ = 4/30000; in this teaching simulator it has no effect on the factorization
  • Period evaluation: none; the period comes from the order finding alone
  • Base: fixed a = 2; no further bases are tried
  • Deterministic reading: The individual outcome is fixed by λ; the frequencies follow the Born rule

Understanding the Bloch Sphere:

  • North pole: |0⟩ state
  • South pole: |1⟩ state
  • Equator: Superposition
Complexity: Shor theoretically O((log N)³); a general exponential quantum advantage is not established, and in the reachable range a classical computer factorizes just as fast (Doc. 176, Doc. 384).

🔧 Troubleshooting & FAQ

Frequently Asked Questions:

❓ Why is my qubit blinking?

Answer: Superposition! The qubit is simultaneously 0 and 1. This is correct and intended.

❓ Why doesn't the algorithm find factors?

Possible reasons:
• The number is prime (mathematically correct)
• The order of 2 is odd or 2r/2 ≡ −1 (mod N) → use "📊 Comparison with trial division"
• N is even: then 2 is not a suitable base, and the factor 2 is obvious

❓ Which mode is the best?

Answer: For factorization they are all the same; they use the same order finding. "🚀 Start order finding" additionally reports primes.

❓ What does "is PRIME" mean?

Answer: This is a correct result. Prime numbers mathematically cannot be factorized; trial division has confirmed that N has no divisor up to √N.

Fixing Problems:

Problem: "Order finding with base a = 2 found no factors"
Solution: N is composite, but base 2 is unsuitable for this N. Use "📊 Comparison with trial division".
Problem: "No factors found" for a prime
Solution: The modes "⚛️ Order finding (quick)" and "🧠 Bell + Grover + order finding" do not check for primes. Use "🚀 Start order finding".
🎯 Best Learning Strategy:
1. Start with "🚀 Start order finding" for small numbers
2. Use "📊 Comparison with trial division" for borderline cases
3. Consciously test primes vs. composite numbers
4. Experiment with Quantum Gates for understanding
5. Understand the mathematical foundations
