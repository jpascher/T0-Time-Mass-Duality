🧠 Was ist FFGFT?

FFGFT (Fundamentale Fraktale Geometrische Feldtheorie / T0-Zeit-Masse-Dualität) ist ein deterministisches Quanten-Framework, das keine Qubits benötigt. Stattdessen verwendet es Energiefelder zur Periodenfindung — das Herzstück von Shors Algorithmus.

Die Grundidee: Statt 2n Qubits zu verwenden, nutzt FFGFT ein Energiefeld. Der Simulator verwendet dabei einen Suchparameter σ (intern σ). Dieser bestimmt die Abtastdichte bei der Periodensuche.

Der FFGFT-Geometrieparameter ξ = 4/30000 erscheint nicht in den Simulatorformeln.

📐 Die FFGFT-Gleichung

∂²E/∂t² = (1 + σ)·∇²E + σ·V·E

Das Energiefeld E wird durch diese Wellengleichung beschrieben. Die Resonanzbedingung σ ≈ 1/(2π·r) führt zur Periodenfindung.

🚨 Browser-Begrenzungen — Warum FFGFT bei großen N versagt

WICHTIG: Die Weyl-Obstruktion ist eine universelle strukturelle Grenze: Kein kompakter Resonanzraum — gleich welcher Technologie — kann die arithmetische Zähldichte T·ln T tragen (Dok. 316, August 2026). FFGFT beschreibt diese Grenze; sie gilt allgemein. Zusätzlich hat der Browser praktische Limits:

1. Baby-Step Giant-Step (BSGS) — Speicher

BSGS benötigt O(√N) Speicher für die Baby-Steps. Für N = 10²⁴ (80 Bits) wären das 10¹² Einträge — das sind ~10 Terabyte RAM!

Browser-Limit: Wir begrenzen auf maxM = 1.000.000 → Das sind nur ~16 MB RAM.

Konsequenz: Perioden mit r > 10¹² werden NICHT gefunden.

🧠 What is FFGFT?

FFGFT (Fundamental Fractal Geometric Field Theory / T0 Time-Mass Duality) is a deterministic quantum framework that requires no qubits. Instead, it uses energy fields for period finding — the core of Shor's algorithm.

The core idea: Instead of using 2n qubits, FFGFT uses an energy field. The simulator uses a search parameter σ (internally σ). It determines the sampling density in the period search.

The FFGFT geometry parameter ξ = 4/30000 does not appear in the simulator formulas.

📐 The FFGFT Equation

∂²E/∂t² = (1 + σ)·∇²E + σ·V·E

The energy field E is described by this wave equation. The resonance condition σ ≈ 1/(2π·r) leads to period finding.

🚨 Browser Limitations — Why FFGFT fails for large N

IMPORTANT: The Weyl obstruction is a universal structural limit: no compact resonance space — regardless of technology — can carry the arithmetic counting density T·ln T (Doc. 316, August 2026). FFGFT describes this limit; it holds universally. Additionally, the browser has practical limits:

1. Baby-Step Giant-Step (BSGS) — Memory

BSGS requires O(√N) memory for baby steps. For N = 10²⁴ (80 bits), that would be 10¹² entries — that's ~10 Terabytes of RAM!

Browser Limit: We limit to maxM = 1,000,000 → That's only ~16 MB of RAM.

Consequence: Periods with r > 10¹² will NOT be found.

🔧 Two separate parameters

ξ = 4/30000 ≈ 1.333·10⁻⁴ is the FFGFT geometry parameter. It is fixed and not adjustable and has no operational connection to factorisation.

The simulator uses internally a numerical search parameter (formerly now denoted σ). It determines the sampling density in the period search — an algorithmic heuristic, not a physical quantity.

The formula σ ≈ 1/(2π·r) shown in the simulator describes the search parameter σ, not the FFGFT geometry parameter.

For large periods r (large N), σ becomes extremely small → hard to measure. This is not a bug, it's physics!
